# 贡献者公约行为准则

## 我们的承诺

作为社区成员、贡献者和领导者，我们承诺让每个人在我们的社区中获得不受骚扰的体验，无论其年龄、体型、明显或不明显的残疾状况、民族、性别特征、性别认同与表达、经验水平、教育程度、社会经济地位、国籍、外貌、种族、种姓、肤色、宗教信仰或性取向如何。

我们承诺以有助于营造开放、包容、多样化、具有包容性和健康的社区的方式来行动和互动。

## 我们的准则

有助于营造积极环境的示例行为包括：

- 对他人表现出同理心和善意
- 尊重不同的观点、立场和经历
- 给予和优雅接受建设性的反馈
- 承担责任并为影响到他人而道歉，从经验中学习
- 注重团队整体的最佳利益，而不仅仅是个人的最佳利益

不可接受的行为示例包括：

- 使用带有性含义的语言或图像，以及任何形式的性关注或追求
- 恶意挑衅、侮辱或贬低性言论，人身或政治攻击
- 公开或私下的骚扰
- 未经明确许可，发布他人的私人信息，如物理地址或电子邮件地址
- 在专业环境中可能被认为不适当的其他行为

## 执行责任

社区领导有责任明确并执行我们可接受行为的标准，并对任何他们认为不当、威胁、冒犯或有害的行为采取适当且公平的纠正措施。

社区领导有权和责任移除、编辑或拒绝不符合此行为准则的评论、提交、代码、维基编辑、问题和其他贡献，并在适当时通报管理决定的理由。

## 范围

本行为准则适用于所有社区空间，也适用于个人在公共空间代表社区时的情况。代表我们社区的示例包括使用官方电子邮件地址、通过官方社交媒体账户发帖或在线上或线下活动中担任指定代表。

## 执行

辱骂、骚扰或以其他方式不可接受行为的实例可向负责执行的社区领导人报告，邮箱为 **security@openpawz.com**。所有投诉都将及时、公正地审查和调查。

所有社区领导均有义务尊重任何事件举报者的隐私和安全。

## 执行指南

社区领导在确定其认为违反此行为准则的任何行为的后果时，将遵循这些社区影响指南：

### 1. 纠正

**社区影响**：使用不当语言或其他在社区内被认定为不专业或不受欢迎的行为。

**后果**：来自社区领导的私下书面警告，阐明违规的本质，并解释为何该行为是不恰当的。可能会要求公开道歉。

### 2. 警告

**社区影响**：通过单一事件或一系列行为造成的违规。

**后果**：警告持续不良行为的后果。在指定时间内不得与相关人士互动，包括未经请求与执行行为准则的人的互动。这包括在社区空间和社交媒体等外部渠道避免互动。违反这些条款可能会导致临时或永久封禁。

### 3. 临时封禁

**社区影响**：严重违反社区标准，包括持续的不当行为。

**后果**：在指定时间内暂时禁止以任何方式与社区进行交互或公开交流。在此期间不允许与有关人员进行公开或私下互动，包括未经请求与执行行为准则的人的互动。违反这些条款可能导致永久封禁。

### 4. 永久封禁

**社区影响**：显示反复违反社区标准的模式，包括持续的不当行为、对个人的骚扰，或对某一人群的敌对或贬低行为。

**后果**：永远禁止在社区内部以任何方式进行公开互动。
