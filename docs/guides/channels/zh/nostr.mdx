# Nostr

连接到 Nostr 去中心化网络，让用户可以通过任何 Nostr 客户端与您的代理进行聊天。

## 设置

1. 为您的机器人生成 Nostr 密钥对（或使用现有的密钥对）
2. 在 Pawz 中，转到 **设置 → 频道**
3. 选择 **Nostr**
4. 输入：
   - **私钥** — 机器人的 nsec 密钥
   - **中继** — 以逗号分隔的中继 URL（例如：`wss://relay.damus.io,wss://nos.lol`）
5. 启动频道

## 配置

| 字段 | 必需 | 描述 |
|-------|----------|-------------|
| 私钥 | 是 | 机器人的 Nostr 私钥 (nsec) |
| 中继 | 是 | 连接的中继 URL |
| 直接消息策略 | 是 | 谁可以给机器人发送消息 |
| 允许用户 | 用于白名单 | Nostr 公钥 (npub) |

## 功能

- 公开 kind-1 文本笔记回复 (NIP-01)
- NIP-04 加密直接消息 (kind-4)
- 每用户的会话和记忆
- 提示注入扫描
- 通过频道路由规则进行代理路由
- 多中继支持
- BIP-340 Schnorr 签名事件
- ECDH 共享密钥 + AES-256-CBC 加密用于直接消息

:::info 支持加密直接消息
该桥接支持使用 ECDH + AES-256-CBC 的 **NIP-04 加密直接消息** (kind-4 事件)。这与所有主要的 Nostr 客户端兼容（Damus、Amethyst、Primal 等）。NIP-44（新的加密标准，配有 NIP-17 礼物包装）计划在未来的版本中发布。
:::

### 路线图

| 功能 | 状态 |
|---------|--------|
| NIP-04 加密直接消息 | ✅ 已实现 |
| NIP-44 加密直接消息（增强隐私） | 计划中 |

## 提示

- 使用多个中继以提高可靠性
- 机器人的公钥 (npub) 从私钥自动推导
- 用户可以在任何 Nostr 客户端上通过其 npub 查找您的机器人
- 考虑发布一个 NIP-05 标识符以提高可发现性
