# Mattermost

连接到自托管的 Mattermost 实例。由于 Mattermost 为自托管，所有数据都保留在您的基础设施内部，结合 Pawz 的本地优先架构，数据永远不会离开您的网络。

## 安装配置

1. 在 Mattermost 管理面板中，进入 **集成 → 机器人账户** 并创建一个机器人
2. 复制机器人令牌
3. 在 Pawz 中，转到 **设置 → 频道**
4. 选择 **Mattermost**
5. 输入：
   - **服务器 URL** — 例如，`https://mattermost.yourcompany.com`
   - **机器人令牌** — 从 Mattermost 管理面板获取
6. 启动此频道

## 配置

| 字段 | 必需 | 说明 |
|-------|----------|-------------|
| 服务器 URL | 是 | Mattermost 实例 URL |
| 机器人令牌 | 是 | 机器人访问令牌 |
| DM 策略 | 是 | 谁可以给机器人发消息（开放、白名单或配对） |
| 允许用户 | 针对白名单 | Mattermost 用户名 |

## 连接

Pawz 通过 Mattermost 的 **WebSocket API** 进行实时消息传输。机器人使用机器人令牌进行身份验证，并监听添加至频道的新帖子，以及直接私信。

## 功能特性

- **私信和频道消息** 通过 WebSocket（实时，无轮询）
- **线程支持** — 回复保留在正确的线程上下文中
- **每用户会话** 在对话中保持持久记忆
- **提示注入扫描** 对所有传入消息进行扫描
- **代理路由** 通过频道路由规则 — 不同频道对应不同代理
- **频道特定上下文** — 精简上下文策略实现快速、经济的回复

## 故障排除

| 问题 | 解决方法 |
|---------|-----|
| 机器人无法连接 | 验证服务器 URL 包含协议（`https://`）且机器人令牌有效 |
| 机器人在频道中不响应 | 在 Mattermost UI 中将机器人添加到频道（邀请到频道） |
| 消息延迟 | 在管理面板中检查 Mattermost WebSocket 健康状态 → **系统控制台 → 环境 → WebSocket** |
| 身份验证失败 | 确保在 **系统控制台 → 集成 → 机器人账户** 中启用机器人账户 |

## 提示

:::tip
- **自托管 = 完全掌控** — Mattermost 在您的基础设施上运行，符合 Pawz 的隐私优先方法。
- **使用频道路由** 将不同代理分配给不同 Mattermost 频道（例如，`#dev` → 代码代理，`#support` → 客服机器人）。
- **机器人令牌永不过期** — 与用户会话不同，机器人令牌始终保持有效，直到明确吊销。
:::
