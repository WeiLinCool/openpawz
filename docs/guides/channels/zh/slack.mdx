# Slack

将 Slack 机器人连接到您的 Pawz 代理。

## 设置

1. 访问 [api.slack.com/apps](https://api.slack.com/apps) 并创建新应用
2. 在 **OAuth & Permissions** 下，添加机器人令牌范围：
   - `chat:write`
   - `channels:history`
   - `im:history`
   - `im:read`
   - `im:write`
3. 将应用安装到您的工作空间
4. 复制 **Bot User OAuth Token**（以 `xoxb-` 开头）
5. 在 Pawz 中，转到 **设置 → 频道**
6. 选择 **Slack**
7. 粘贴您的机器人令牌
8. 启动频道

## 配置

| 字段 | 必需 | 描述 |
|-------|----------|-------------|
| 机器人令牌 | 是 | 来自 Slack 的 `xoxb-` 令牌 |
| 直接消息策略 | 是 | 谁可以给机器人发消息 |
| 允许用户 | 用于白名单 | Slack 用户名 |

## 功能

- 直接消息和频道提及
- 每用户的会话和记忆
- 提示注入扫描
- 通过频道路由规则进行代理路由
- 线程支持

## 路由

将 Slack 频道或用户路由到特定代理：

- **频道 ID 过滤器** — 路由来自特定 Slack 频道的消息（使用频道 ID，而不是名称）
- **用户过滤器** — 路由来自特定 Slack 用户的消息

## 提示

- 使用邀请命令将机器人邀请到您希望它响应的频道：`/invite @YourBot`
- 当被提及（`@YourBot`）或在私信中时，机器人才会回应
- 如果您想要代理主动发送消息，请单独使用 Slack 技能
