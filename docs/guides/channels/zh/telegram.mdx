# Telegram 频道

将 Telegram 机器人连接到您的 Pawz 代理。

## 设置

1. 在 Telegram 上通过 [@BotFather](https://t.me/BotFather) 创建一个机器人
2. 复制机器人令牌(token)
3. 在 Pawz 中，转到 **设置 → 频道**
4. 选择 **Telegram**
5. 粘贴您的机器人令牌
6. 配置：
   - **私信策略** — 开放 / 允许列表 / 配对
   - **允许用户** — Telegram 用户名(用于允许列表模式)
7. 启动频道

## 配置

| 字段 | 必需 | 说明 |
|-------|----------|-------------|
| 机器人令牌 | 是 | 来自 @BotFather |
| 私信策略 | 是 | 谁可以给机器人发消息 |
| 允许用户 | 适用于允许列表 | 用逗号分隔的用户名 |

## 功能

- 支持直接消息和群聊
- 每个用户的会话带记忆功能
- 超长消息自动拆分为符合 Telegram 的 4096 字符限制
- 所有传入消息均进行提示注入扫描
- 通过频道路由规则进行代理路由

## 路由

默认情况下，所有 Telegram 消息都发送到您的默认代理。要将特定用户或群组路由到不同代理，请在 **设置 → 频道 → 路由** 中添加路由规则。

## 提示

- 在 @BotFather 中设置您机器人的描述和简介文本，以获得更好的体验
- 使用 @BotFather 中的 `/setcommands` 添加命令提示
- 对于群聊，将机器人设置为 **群隐私：禁用**，这样它可以查看所有消息
