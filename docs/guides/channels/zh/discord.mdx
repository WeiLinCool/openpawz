# Discord

将 Discord 机器人连接到您的 Pawz 智能体。

## 设置

1. 前往 [Discord 开发者中心](https://discord.com/developers/applications)
2. 创建一个新的应用程序  
3. 前往 **机器人** → 创建机器人 → 复制令牌
4. 在特权网关意图下启用**消息内容意图**
5. 使用 OAuth2 URL 生成器将机器人邀请到您的服务器（范围：`bot`，权限：`发送消息`，`读取消息历史记录`）
6. 复制您的**服务器（公会）ID**：在 Discord 中启用开发者模式 → 设置 → 应用设置 → 高级，然后右键点击服务器名称并选择**复制服务器 ID**
7. 在 Pawz 中，前往 **设置 → 频道**
8. 选择 **Discord**
9. 粘贴您的**机器人令牌**和**服务器 ID**
10. 启动频道

## 配置

| 字段 | 必需 | 描述 |
|-------|----------|-------------|
| 机器人令牌 | 是 | 来自 Discord 开发者门户 |
| 服务器（公会）ID | 否 | 右键点击您的服务器 → 复制服务器 ID（首先启用开发者模式）。用于服务器管理功能，如列出频道、角色和成员。 |
| 私信政策 | 是 | 谁可以给机器人发送私信 |
| 允许的用户 | 用于白名单 | Discord 用户名 |

## 功能

- 私信和服务器频道消息
- 每个用户的带记忆会话
- 长消息自动拆分以适应 Discord 的 2000 字符限制
- 提示注入扫描
- 通过频道路由规则进行智能体路由

## 路由

使用路由规则将特定频道或用户路由到不同的智能体：

- **频道 ID 过滤器** — 将来自特定 Discord 频道的消息进行路由
- **用户过滤器** — 将来自特定用户的消息进行路由

## 提示

- 如果您还希望智能体通过 Discord 技能主动发送消息，请在技能保险库中使用 `DISCORD_BOT_TOKEN`
- 机器人默认响应提及和私信
