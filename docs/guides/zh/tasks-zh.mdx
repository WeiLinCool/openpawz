# 任务

任务视图是一个看板，用于管理智能体可以领取和执行的工作项。

## 看板列

| 列 | 状态 | 含义 |
|--------|--------|---------|
| **收件箱** | `inbox` | 新任务，未分配 |
| **已分配** | `assigned` | 已分配智能体，尚未开始 |
| **进行中** | `in_progress` | 智能体正在进行中 |
| **审核中** | `review` | 已完成，需人工审核 |
| **受阻** | `blocked` | 等待某些条件 |
| **已完成** | `done` | 完成 |

拖拽任务在各列之间移动以更改状态。

## 创建任务

1. 点击 **新建任务**
2. 填写：
   - **标题** — 需要做什么
   - **描述** — 细节和上下文
   - **优先级** — 低 / 中 / 高 / 紧急
   - **分配智能体** — 哪个智能体处理
   - **模型覆盖** — 为此任务使用特定模型

## 优先级级别

| 优先级 | 使用时机 |
|----------|-------------|
| `低` | 锦上添花，无截止日期 |
| `中` | 标准优先级 |
| `高` | 重要，尽快办 |
| `紧急` | 立即处理 |

## 多智能体分配

任务可以有多个智能体：

- **负责人** — 主导任务的责任智能体
- **协作者** — 协助负责智能体

## 使用 cron 计划调度

任务可以根据计划运行：

1. 打开一个任务
2. 设置 **cron 时间表**（标准 cron 语法）
3. 启用 **cron**

引擎每 60 秒检查一次到期的任务。

### Cron 示例

```
0 9 * * *       每天上午9点
0 */2 * * *     每两小时
0 9 * * 1-5     工作日上午9点
*/30 * * * *    每30分钟
```

## 活动动态

每个任务都有一个实时活动动态显示：

| 事件 | 描述 |
|-------|-------------|
| `created` | 任务已创建 |
| `assigned` | 已分配智能体 |
| `status_change` | 任务移至新列 |
| `comment` | 人添加了注释 |
| `agent_started` | 智能体开始工作 |
| `agent_completed` | 智能体完成 |
| `agent_error` | 智能体遇到错误 |
| `cron_triggered` | 计划运行触发 |

动态过滤器：**全部**、**仅任务** 或 **状态变更**。

## 任务状态

每个任务都有一个 **看板状态**（它位于哪一列）和一个跟踪智能体进度的潜在 **执行状态**：

| 看板列 | 执行状态 | 描述 |
|-------------|-----------------|-------------|
| **收件箱** | `pending` | 还没有被任何智能体拾取 |
| **已分配** | `pending` | 已分配智能体但尚未启动 |
| **进行中** | `in_progress` | 智能体正在积极执行 |
| **审核中** | `completed` | 智能体已完成 — 等待人工审核 |
| **受阻** | `failed` / `cancelled` | 出现问题或被停止 |
| **已完成** | `completed` | 完全完成并获批准 |

:::info
当智能体遇到错误时，任务移动到 **受阻** 并具有 `failed` 执行状态。您可以重新分配或将其移回 **收件箱** 进行重试。
:::

### 取消任务

要取消运行中的任务：

1. 打开任务
2. 将其拖到 **受阻** 或点击 **删除**
3. 智能体会话被中止，执行状态变为 `cancelled`

## 任务模板

通过将 cron 计划调度与预填字段相结合来创建可重用的任务模板：

1. 创建一个具有描述性 **标题** 和 **描述** 的任务
2. 分配智能体并设置 **优先级**
3. 设置 **cron 计划**（例如 `0 9 * * 1-5` 表示工作日早上）
4. 启用 **cron** — 任务将在计划时间重建

### 常见模板模式

| 模板 | Cron | 描述 |
|----------|------|-------------|
| 每日站会 | `0 9 * * 1-5` | 总结昨天的活动 |
| 每小时监控 | `0 * * * *` | 检查服务并报告问题 |
| 周报 | `0 17 * * 5` | 生成周末总结 |
| PR 审查 | `*/30 * * * *` | 检查新的拉取请求 |
| 新闻摘要 | `0 8 * * *` | 研究和汇总新闻 |

:::tip
将模板与 **模型覆盖** 相结合，对日常检查使用更便宜的模型，对复杂分析任务使用强大模型。
:::
