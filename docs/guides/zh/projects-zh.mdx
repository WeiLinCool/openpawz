# 项目 — 文件浏览器

项目视图是内置在Pawz中的本地文件浏览器。它允许您浏览项目文件夹，检查Git状态，并预览文本文件——全部通过Tauri的文件系统API在应用内完成。

## 添加项目

1. 打开**项目**视图
2. 点击**添加文件夹**
3. 选择一个本地目录
4. 文件夹会出现在您的项目列表中，并带有其目录树

### 操作

| 动作 | 描述 |
|--------|-------------|
| **添加文件夹** | 浏览并添加本地目录到您的项目列表 |
| **移除文件夹** | 从列表中删除项目（磁盘上的文件不会被删除） |
| **刷新** | 重新读取目录树并更新Git状态 |

项目保存在**localStorage**中，所以即使应用重启，您的项目列表也会保留。

## 文件树

每个项目显示一个可展开的目录树：

- **延迟加载**：子目录仅在展开时才被读取，使大型项目的UI保持响应
- **文件图标**：文件和文件夹有视觉区分
- **点击预览**：点击文本文件会打开只读预览

### 文件预览

文件查看器提供文件内容的**只读**文本预览。对于无需离开Pawz即可快速检查很有用。

:::info
文件预览设计为只读。要编辑文件，请使用智能体的`write_file`或`edit_file`工具，或在您首选的编辑器中打开文件。
:::

## Git集成

对于Git仓库项目，Pawz显示丰富的状态信息：

| 字段 | 描述 |
|-------|-------------|
| **分支** | 当前检出的分支 |
| **远程** | 配置的远程URL |
| **未提交文件** | 未提交更改的数量 |
| **超前/落后** | 超前或落后的远程提交数量 |
| **最后一次提交** | 最近的提交消息和哈希值 |

Git信息通过`@tauri-apps/plugin-shell`获取，可通过**刷新**按钮手动刷新。

:::tip
提交或pull后使用刷新按钮，在不重启应用的情况下查看更新的Git状态。
:::

## 安全性

项目视图实施严格的安全边界，防止浏览敏感系统路径。

### 已阻止路径

以下**18个敏感路径模式**会被阻止浏览：

| 模式 | 原因 |
|---------|--------|
| `.ssh` | SSH密钥和配置 |
| `.gnupg` | GPG密钥和密钥环 |
| `.aws` | AWS凭证和配置 |
| `.kube` | Kubernetes配置 |
| `.docker` | Docker凭证 |
| `.gnome-keyring` | GNOME钥匙环目录 |
| `.password-store` | 密码存储目录 |
| `.netrc` | 网络认证凭证 |
| `/etc` | 系统配置 |
| `/root` | 根用户主目录 |
| `/var/log` | 系统日志 |
| `/proc` | 进程信息伪文件系统 |
| `/sys` | 内核/设备伪文件系统 |
| `/dev` | 设备文件系统 |
| `C:\Windows` | Windows系统目录 |
| `C:\Users\*\AppData` | AppData目录 |
| `.openclaw` | OpenClaw配置（包含令牌） |
| `.config/himalaya` | Himalaya邮件配置 |

### 安全事件日志

任何尝试访问已阻止路径的操作将通过`logSecurityEvent()`记录日志，详情如下：

- **工具名称**：尝试执行的操作
- **命令**：被阻止的路径
- **风险级别**：安全分类
- **详细信息**：可读的人类解释
- **是否允许**：对于阻塞路径始终为`false`

:::warning
不能通过UI绕过这些安全限制。它们在应用程序级别强制执行，以保护敏感系统数据不会意外暴露给人工智能智能体。
:::
