# 铸造厂 — 模型和聊天模式

铸造厂是您管理 AI 提供商和创建可重复使用的聊天模式预设的控制中心。它提供**模型**和**聊天模式**两个标签页。

## 模型标签页

模型标签页以卡片形式显示所有配置的 AI 提供商，让您快速概览您的设置。

### 提供商卡片

每个提供商卡片显示：

| 字段 | 描述 |
|-------|-------------|
| **类型** | 提供商类型 (例如 `anthropic`, `openai`, `ollama`, `google`) |
| **端点** | 提供商 API 的基础 URL |
| **模型** | 当前选择的模型 |
| **密钥状态** | 是否配置了 API 密钥 (以徽章形式显示) |
| **默认徽章** | 指示这是否是您的默认提供商 |

### 支持的提供商

| 提供商 | 类型 | 默认端点 |
|----------|------|-----------------|
| Ollama | `ollama` | `http://localhost:11434` |
| OpenAI | `openai` | `https://api.openai.com/v1` |
| Anthropic | `anthropic` | `https://api.anthropic.com` |
| Google | `google` | `https://generativelanguage.googleapis.com/v1beta` |
| DeepSeek | `deepseek` | `https://api.deepseek.com/v1` |
| xAI (Grok) | `grok` | `https://api.x.ai/v1` |
| Mistral | `mistral` | `https://api.mistral.ai/v1` |
| Moonshot/Kimi | `moonshot` | `https://api.moonshot.cn/v1` |
| OpenRouter | `openrouter` | `https://openrouter.ai/api/v1` |
| 自定义 | `custom` | 用户定义 |

### 设置默认提供商

要将提供商设置为默认提供商，请前往**设置 → 高级**，找到提供商卡片，然后单击**设为默认**。除非被智能体或聊天模式覆盖，否则默认提供商用于所有对话。

## 聊天模式标签页

聊天模式是命名的预设，可让您即时在不同的对话配置之间切换。可以把它们看作 AI 行为的"个人资料"。

### 模式属性

| 属性 | 描述 |
|----------|-------------|
| **名称** | 模式的显示名称 |
| **模型** | 此模式激活时使用的 AI 模型 |
| **系统提示** | 为此模式注入的自定义系统提示 |
| **思考水平** | AI 推理深度：`none`, `low`, `medium`, `high` |
| **温度** | 随机性控制 (0.0–2.0) |
| **图标** | 用于快速识别的表情符号或符号 |
| **颜色** | 模式的视觉强调色 |

### 创建聊天模式

1. 打开**铸造厂**视图
2. 切换到**聊天模式**标签页
3. 单击**新模式**
4. 在表单模式中填写模式属性
5. 保存

### 示例模式

| 模式 | 模型 | 温度 | 思考 | 用例 |
|------|-------|-------------|----------|----------|
| 快速聊天 | `claude-3-haiku` | 0.7 | 无 | 快速、轻量级回复 |
| 深度分析 | `claude-opus-4-6` | 0.3 | 高 | 复杂推理任务 |
| 创意写作 | `claude-sonnet-4-6` | 1.0 | 中等 | 故事、头脑风暴 |
| 代码审查 | `gpt-5.1` | 0.2 | 低 | 精确、技术反馈 |

### 管理模式

- **编辑**: 点击模式卡片以打开编辑表单
- **删除**: 移除您不再需要的模式
- **切换**: 在对话过程中使用 `/mode <name>` 斜杠命令激活模式

```
/mode 深度分析
```

### 存储

聊天模式存储在前端 SQLite 数据库中的 `agent_modes` 表中。这意味着它们在会话之间持续存在，并在应用程序重启时立即可用。

:::tip
创建一个"成本节约者"模式，使用像 `claude-3-haiku` 或 `gpt-4.1-nano` 这样的便宜模型来进行简单任务，再创建一个"繁重任务"模式，使用强大的模型处理复杂工作。通过 `/mode` 快速切换以管理成本。
:::

:::info
聊天模式会在整个对话过程中覆盖默认提供商/模型。智能体特定的模型覆盖优先于聊天模式。
:::
