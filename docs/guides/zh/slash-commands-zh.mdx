# 斜杠命令

在任何聊天中键入`/`来访问快速命令。命令按类别组织。

## 聊天

| 命令 | 参数 | 描述 |
|---------|------|-------------|
| `/model` | `<name>` | 切换本次对话的模型 |
| `/think` | `<none\|low\|medium\|high>` | 设置扩展思维级别 |
| `/mode` | `<name>` | 切换智能体模式 |
| `/agent` | `<name>` | 切换到不同的智能体 |
| `/temp` | `<0.0-2.0>` | 设置温度（创意度） |

### 示例

```
/model gemini-2.5-pro
/think high
/temp 0.8
/agent Research Bot
```

## 会话

| 命令 | 参数 | 描述 |
|---------|------|-------------|
| `/clear` | — | 清除当前会话 |
| `/compact` | — | 压缩会话（汇总旧消息） |
| `/new` | `[label]` | 新建一个会话 |
| `/rename` | `<label>` | 重命名当前会话 |

## 记忆

| 命令 | 参数 | 描述 |
|---------|------|-------------|
| `/remember` | `<text>` | 手动存储记忆 |
| `/forget` | `<id>` | 按 ID 删除记忆 |
| `/recall` | `<query>` | 搜索记忆并显示结果 |

### 示例

```
/remember 我更喜欢 TypeScript 而不是 JavaScript
/recall 用户喜欢什么编程语言？
/forget mem_abc123
```

## 工具

| 命令 | 参数 | 描述 |
|---------|------|-------------|
| `/web` | `<query>` | 搜索网络 |
| `/img` | `<prompt>` | 生成图像 |
| `/exec` | `<command>` | 执行 Shell 命令 |

### 示例

```
/web 最新的 Rust 发行说明
/img 雨中赛博朋克猫
/exec ls -la ~/projects
```

## 配置

| 命令 | 参数 | 描述 |
|---------|------|-------------|
| `/help` | — | 显示可用命令 |
| `/status` | — | 显示引擎状态和配置 |
| `/debug` | — | 切换调试模式 |

## 自动补全

当您输入命令时，自动补全下拉列表会显示带有描述的匹配命令。使用箭头键导航并按 Enter 选择。
