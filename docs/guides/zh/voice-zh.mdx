# 语音与TTS

Pawz 支持文本转语音，使智能体可以朗读他们的回应。

## 安装设置

前往 **设置 → 语音** 配置 TTS。

## 提供商

### Google Cloud TTS

无需 API 密钥 — 使用免费的 Web 端点。

**Chirp 3 HD 语音：**
Puck, Charon, Kore, Fenrir, Leda, Orus, Zephyr, Aoede, Callirhoe, Autonoe

**Neural2 语音：**
en-US-Neural2-A 通过 F

**Journey 语音：**
en-US-Journey-D, en-US-Journey-F, en-US-Journey-O

### OpenAI TTS

需要 OpenAI API 密钥。

**语音：** alloy, ash, coral, echo, fable, nova, onyx, sage, shimmer

### ElevenLabs

需要 `ELEVENLABS_API_KEY`。

**语音：** Sarah, Charlie, George, Callum, Liam, Charlotte, Alice, Matilda, Will, Jessica, Eric, Chris, Brian, Daniel, Lily, Bill

**模型：**
| 模型 | 最适合 |
|-------|----------|
| `eleven_multilingual_v2` | 多语言，质量最高 |
| `eleven_turbo_v2_5` | 低延迟，英语重点 |
| `eleven_monolingual_v1` | 仅英语，遗产版 |

**额外设置：**
- **稳定性** (0–1，默认 0.5) — 数值更高 = 更一致
- **相似度提升** (0–1，默认 0.75) — 数值更高 = 更接近参考语音

## 设置

| 设置 | 默认值 | 描述 |
|---------|---------|-------------|
| **提供商** | — | Google / OpenAI / ElevenLabs |
| **语音** | — | 从选定提供商处获取的语音名称 |
| **速度** | 1.0 | 播放速度倍数 |
| **语言** | — | 语言代码（支持13种） |
| **自动朗读** | 关闭 | 自动朗读每一个回应 |

## 语音转文字 (STT)

Pawz 使用 OpenAI Whisper 进行语音转文字转录：

| 后端 | 设置 | 延迟 | 成本 |
|---------|-------|---------|------|
| **Whisper API** | OpenAI API 密钥（来自模型设置） | ~1–2秒 | $0.006/分钟 |
| **Whisper 本地** | 安装 `whisper` 二进制文件 | ~3–5秒 | 免费 |

STT 用于谈话模式和任何语音输入功能。音频捕获为 WebM/Opus（或 OGG 回退），base64编码，并发送到 Whisper 终端进行转录。

### 音频捕捉设置

麦克风输入使用这些 Web Audio 限制：

| 设置 | 数值 |
|---------|-------|
| 回声消除 | 已启用 |
| 噪音抑制 | 已启用 |
| 采样率 | 16 kHz |
| 格式 | `audio/webm;codecs=opus`（首选） |

## 语音活动检测 (VAD)

谈话模式包括内置的语音活动检测，以避免向转录 API 发送静音：

| 参数 | 数值 | 描述 |
|-----------|-------|-------------|
| 录音窗口 | 8秒 | 以8秒为块进行录音 |
| 最小音频大小 | 8 KB | 低于8KB的块被视为静音并跳过 |
| 周期间延迟 | 500毫秒 | 错误后的录音周期之间的短暂暂停 |
| 空白转录 | 跳过 | 如果 Whisper 返回空白文本，则重新开始周期 |

:::info
VAD 通过检查每个录音块的大小来工作。非常短或静音的录音会产生小文件，这些文件在发送到 Whisper 之前被自动丢弃。
:::

## 谈话模式

点击聊天标题栏中的麦克风图标进入谈话模式。您的语音被转录并发送给智能体，回复则被朗读出来。

需要以下任一条件：
- **Whisper API** 技能（OpenAI API 密钥）
- **Whisper 本地** 技能（安装 `whisper` 二进制文件）

### 谈话模式如何工作

1. **监听** — 麦克风分 8 秒的窗口捕捉音频
2. **转录** — 音频发送到 Whisper STT → 文本
3. **处理** — 转录的文本作为聊天消息发送给您的智能体
4. **朗读** — 智能体的回复通过您配置的 TTS 提供商合成
5. **重复** — 回放完成后下一个录音循环开始

### 语音命令模式与听写模式

| 模式 | 行为 | 使用情形 |
|------|----------|----------|
| **语音命令**（默认） | 每次发言都会作为一个独立的聊天消息发送 | 发出指令，提问题 |
| **听写** | 发言会被累积到一个文本缓冲区 | 编写长篇文章，电子邮件 |

在**语音命令模式**下，每个 8 秒的录音窗口被独立地转录并发送给智能体。智能体响应并口头回应，然后下一个循环开始。

要使用**听写模式**，在您的话语开头说 "听写" 或 "输入" — 智能体会将您的演讲累积到文档中，而不是进行对话式回应。
