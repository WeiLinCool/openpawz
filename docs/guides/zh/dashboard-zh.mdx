# 仪表板 & 今日

仪表板（也称为今日视图）是您在Pawz中的首页。它通过气象小组件、任务列表、快速操作按钮和活跃智能体的个性化问候为您提供一天的概览。

## 问候语

仪表板显示一天中不同时候变化的时间基础问候语：

| 时间 | 问候语 |
|------|----------|
| 凌晨12点至中午12点 | 早上好 |
| 中午12点至下午5点59分 | 下午好 |
| 下午6点以后 | 晚上好 |

问候语伴随着您激活智能体的头像。

## 天气组件

仪表板包含由 [wttr.in](https://wttr.in) 提供动力的天气组件。

- **无需API密钥** — wttr.in 是一项免费的开放服务
- 显示您当前位置的当前状况
- 加载仪表板时自动更新

:::tip
wttr.in 服务使用您的IP地址进行地理位置定位。如果您使用VPN，天气信息将反映VPN服务器的位置。
:::

## 任务列表

一个轻量级任务管理器直接集成到仪表板中，用于快速日常规划。

### 操作

| 操作 | 描述 |
|--------|-------------|
| **创建** | 添加具有标题的新任务 |
| **切换** | 标记任务已完成或未完成 |
| **编辑** | 更新任务的标题 |
| **删除** | 从列表中移除任务 |

仪表板上的任务存储在 **localStorage** 中，与完整看板任务管理系统（使用引擎的SQLite数据库）是分开的。请将它们视为快速个人提醒，而不是智能体管理的任务。

:::info
对于具有智能体分配、cron计划和看板工作流程的全功能任务管理，请使用**任务**视图。
:::

## 快速操作按钮

仪表板提供一键快速操作，将预建提示发送给您的活跃智能体：

| 按钮 | 遂行功能 |
|--------|-------------|
| **晨间简报** | 询问智能体准备包含天气、日历、任务和新闻的早晨摘要 |
| **汇总收件箱** | 询问智能体汇总最近的电子邮件和消息 |
| **今天有什么？** | 询问智能体概述您今天的所有安排 |

这些操作打开聊天视图并立即发送相应的提示，让您的智能体能够立即开始工作。

## 智能体头像显示

您当前活跃智能体的头像会在仪表板上显著显示。Pawz使用了基于精灵图的头像系统，带有50个唯一的头像，每个头像分配来自7色色板的颜色。

:::tip
在**智能体**视图中自定义您智能体的头像和颜色，使仪表板具有个人特色。
:::

## 技能输出组件

社区集成和扩展可以在仪表板上使用**技能输出组件**显示实时数据。当智能体使用 `skill_output` 工具时，数据会被持久保存到SQL数据库中，并在今日页面上呈现为组件卡片。

### 工作原理

1. 社区技能在其 `pawz-skill.toml` 清单中定义了 `[widget]` 部分
2. 智能体调用 `skill_output` 并携带结构化JSON数据（例如CRM交易表、股票价格或系统指标）
3. 数据存储在 `skill_outputs` 表中
4. 仪表板使用声明的字段定义渲染组件 — 支持文本、数字、货币、徽章和日期列类型

### 组件类型

| 类型 | 描述 |
|------|-------------|
| `table` | 具有可排序列的表格数据 |
| `stat` | 带有标签和值的单一指标 |
| `list` | 有序或无序项目列表 |

### 刷新

组件可以声明刷新间隔（例如 `refresh = "5m"`）以使用最新数据自动重新渲染。智能体的cron任务可以配置为定期更新技能输出。

:::tip
将技能输出组件与**事件驱动触发器**结合使用，以在接收Webhook或智能体通信时实时更新仪表板数据。
:::
