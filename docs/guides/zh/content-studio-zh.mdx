# 内容工作室

内容工作室是Pawz内的内置文档编辑器，用于直接起草和管理文本内容。编写markdown、HTML或纯文本，并可以选择使用AI一键改进您的写作。

## 文档管理

### 创建文档

1. 打开**内容**视图
2. 点击**新建文档**
3. 输入标题并选择内容类型
4. 在编辑器中开始写作

### 内容类型

| 类型 | 描述 |
|------|-------------|
| **Markdown** | 标准markdown格式 |
| **HTML** | 原生HTML内容 |
| **纯文本** | 无格式文本 |

### 操作

| 操作 | 描述 |
|--------|-------------|
| **创建** | 使用标题和内容类型开始新文档 |
| **编辑** | 修改现有文档的标题、类型或内容 |
| **保存** | 将更改保存到数据库 |
| **删除** | 永久移除文档 |

## 编辑器

编辑器提供了一个全宽度的文本区域，专为专注写作而优化：

- **实时词数统计**: 显示在编辑器下方，并随您的输入更新
- **标题编辑**: 点击文档标题以在行内重命名它
- **内容类型选择器**: 在markdown、HTML和纯文本之间切换

### 文档侧边栏

左侧边栏列出了您所有的文档：

| 列 | 描述 |
|--------|-------------|
| **标题** | 文档名称 |
| **词数** | 文档中的总词数 |
| **上次更新** | 最近编辑的时间戳 |

点击侧边栏中的任何文档在编辑器中打开。

## AI 改进

内容工作室的突出特色是**AI 改进**——一个一键按钮，将您的文档内容发送到聊天引擎进行AI驱动的文本改进。

### 工作原理

1. 在编辑器中编写或粘贴内容
2. 点击**AI 改进**按钮
3. 内容被发送到您的活动AI模型，并指示其改进清晰度、语法和风格
4. 改进版本被返回并可供审阅

:::tip
AI 改进使用您当前配置的模型和提供商。为了在长篇内容上获得最佳效果，请使用功能强大的模型，如Claude Sonnet或GPT-5.1。
:::

## 存储

文档存储在**前端SQLite**数据库的 `content_documents` 表中。这意味着：

- 文档在应用程序重启后仍然存在
- 文档存储在您的机器上
- 没有云同步—您的内容保持私密

### 模式

| 列 | 类型 | 描述 |
|--------|------|-------------|
| `id` | UUID | 唯一文档标识符 |
| `title` | 文本 | 文档标题 |
| `content` | 文本 | 完全文档内容 |
| `content_type` | 文本 | `markdown`、`html`或`plaintext` |
| `word_count` | 整数 | 缓存词数 |
| `created_at` | 时间戳 | 创建时间 |
| `updated_at` | 时间戳 | 上次修改时间 |

:::info
内容工作室文档与研究报告发现和智能体生成的文件是分开的。它们是在Pawz中您的个人写作空间。
:::
