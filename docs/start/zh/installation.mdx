# 安装

<Note>首次构建需要几分钟时间，Rust 会编译依赖项。后续构建会增量完成且快得多。</Note>

## 先决条件

| 要求 | 版本 | 安装 |
|-------------|---------|---------|
| **Node.js** | 18+ | [nodejs.org](https://nodejs.org/) |
| **Rust** | 最新稳定版 | [rustup.rs](https://rustup.rs/) |
| **平台依赖** | — | 参见[Tauri 先决条件](https://v2.tauri.app/start/prerequisites/) |

### Linux (Debian/Ubuntu)

```bash
sudo apt update
sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file \
  libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev
```

### macOS

```bash
xcode-select --install
```

### Windows

安装 [Visual Studio 构建工具](https://visualstudio.microsoft.com/visual-cpp-build-tools/)，并选择"C++ 桌面开发"工作负载及 Windows 10/11 SDK。

## 克隆与构建

```bash
# 克隆仓库
git clone https://github.com/OpenPawz/openpawz.git
cd openpawz

# 安装前端依赖
pnpm install

# 以开发模式运行（热重载）
pnpm tauri dev
```

首次构建将花费几分钟时间，Rust 会编译所有依赖项。后续构建是增量式的。

## 生产构建

```bash
pnpm tauri build
```

构建的应用程序将在 `src-tauri/target/release/bundle/` — 平台特定的安装包（.dmg、.deb、.msi 等）。

## 验证

启动后，OpenPawz 会打开今日仪表板。前往**设置 → 提供商**以配置您的第一个 AI 提供商，然后创建智能体并开始聊天。

## 推荐：Ollama（本地 AI）

Ollama 为 OpenPawz 中的三个系统提供支持：**低成本工具执行**、**语义内存**和**离线聊天**。我们强烈建议您安装它以实现零成本本地推理，但这些角色也可以由任何提供商的云模型填充。

```bash
# 安装 Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 工作模型 — 执行 MCP 工具调用（任何模型都可行；本地为 $0）
ollama pull qwen2.5-coder:7b

# 嵌入模型 — 语义内存 + 工具发现（任何嵌入模型都可以；本地为 $0）
ollama pull nomic-embed-text

# 聊天后备 — 在没有 API 时离线对话
ollama pull llama3.2:3b
```

Pawz 会自动在 `localhost:11434` 上检测 Ollama，在需要时自动启动它，并在首次启动时自动拉取嵌入模型。

### 工作模型设置

工作模型（`worker-qwen`）是让工具执行免费的关键。当您的云端 AI 智能体（Gemini、Claude、GPT）需要通过 [MCP 桥接](/guides/mcp-bridge)运行工具时，它会委托给本地工作者而不是发起额外的 API 调用。

要设置工作进程：

1. 前往**设置 → 高级 → Ollama**
2. 点击**设置工作智能体**
3. 这将创建一个具有合适系统提示的自定义 `worker-qwen` 模型

或在命令行中：

```bash
ollama pull qwen2.5-coder:7b  # 基础模型 (~4.7 GB)
```

设置中的一步式安装会自动创建优化的 `worker-qwen` 变体。

<Note>
没有 Ollama 时，工具调用将通过您付费的 AI 提供商。有了 Ollama，它们是免费的。查看[MCP 桥接指南](/guides/mcp-bridge)了解完整架构师/工作者架构。
</Note>
