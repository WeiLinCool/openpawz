## 11 个同时渠道

**没有其他 AI 智能体平台能同时连接这么多平台。** 一个应用，一组智能体，11 个实时桥接 — 同时运行。在 Telegram 上有一个用户联系您，另一个在 Discord 上，还有一个在 Slack 上 — 相同的智能体（或不同的智能体）立即在每个平台上回应。

| 渠道 | 类型 | 主要功能 |
|---|---|---|
| Telegram | 机器人 API | 私信政策、用户白名单、配对审批 |
| Discord | 机器人 | @ 回复模式、私信政策、用户审批 |
| Slack | Socket 模式 | 应用 + 机器人令牌、@ 回复、私信政策 |
| Matrix | 客户端 | 主服务器认证、房间响应、私信政策 |
| IRC | TLS 客户端 | 多频道加入、频道响应切换 |
| WhatsApp | 网页桥接 | Evolution API、Docker 管理、二维码配对、群组响应 |
| Twitch | 聊天 | OAuth 机器人、多频道、@ 要求切换 |
| Mattermost | 机器人 | 服务器 + 令牌认证、@ 回复、私信政策 |
| Nextcloud Talk | 机器人 | 用户名/密码认证、群组响应切换 |
| Nostr | 中继 | NIP-04 加密私信、Ed25519 签名、多中继 WebSocket |
| Webchat | 内建 | TLS WebSocket、Cookie 认证、内联 HTML/JS/CSS、会话管理 |

<Columns cols={2}>
  <Card title="统一访问控制">
    每个渠道都有相同的接口：启动/停止、配置获取/设定、状态、批准/拒绝/移除用户。在所有 11 个平台上保持一致的行为。
  </Card>
  <Card title="每渠道智能体路由">
    为每个渠道分配特定智能体。您的支持机器人为 Discord 提供服务，您的研究智能体处理 Slack，您的个人助理处理 Telegram — 全部来自一个应用。
  </Card>
  <Card title="渠道路由规则">
    基于规则的路由引擎，采用首次匹配逻辑。基于渠道、用户、关键词或自定义条件将消息路由到特定智能体。
  </Card>
  <Card title="智能消息分割">
    长响应自动在适当的平台边界处分割。Discord 的 2000 字符限制，Telegram 的 4096 字符限制 — 处理透明。
  </Card>
</Columns>

## 内存 — 任何智能体平台中最先进的检索系统

大多数 AI 工具在对话之间忘记所有内容。OpenPawz 拥有最复杂的内存系统可供使用 — **四种检索策略相结合**。

<Columns cols={2}>
  <Card title="混合检索">
    **没有其他平台这样做。** BM25 全文搜索 + 向量相似度（余弦）结合加权合并。您会得到关键词搜索的精度和语义搜索的灵活性 — 齐备。
  </Card>
  <Card title="MMR 重新排序">
    基于 Jaccard 多样性的最大边际相关性确保回想的记忆既相关又多样。不再获得五份相同记忆的副本。
  </Card>
  <Card title="时间衰减">
    带有 30 天半衰期的指数衰减。近期记忆排名高于旧记忆。您的智能体优先考虑当前信息，同时不丢失长期知识。
  </Card>
  <Card title="自动捕获与自动召回">
    关键事实会自动从每次对话中提取并存储向量嵌入。当上下文相关时，在智能体回应前注入记忆 — 零手动工作。
  </Card>
</Columns>

<Columns cols={2}>
  <Card title="记忆宫殿">
    专用界面用于浏览、搜索、编辑和删除记忆。按智能体、主题、日期、类别或相关性分数筛选。关于 AI 知识的完全透明。
  </Card>
  <Card title="重要性评分">
    每个记忆获得一个重要性分数（0-1）。关键事实排名高于随便观察到的信息。系统学会什么是重要的。
  </Card>
  <Card title="记忆回填">
    回顾性地为现有记忆生成向量嵌入。升级您的记忆系统，无需从头开始。
  </Card>
  <Card title="共享与隔离命名空间">
    在默认情况下，所有智能体共享记忆 — 由一个捕获的知识对所有智能体可用。当您需要边界时，隔离每个智能体或每个工作区。

</Columns>

## 安全性 — 零信任、本地优先

OpenPawz 从零开始设计了**零信任、本地优先的安全模型**。这不是后来加的功能 — 这是架构的一部分。

<Columns cols={2}>
  <Card title="100% 本地 — 无云">
    所有数据保持在您的硬件上。无云同步，无遥测，无分析，无远程上报。唯一的出站流量是您显式配置的 AI 提供商。
  </Card>
  <Card title="OS 密钥链凭证">
    API 密钥存储在 macOS 密钥链、Windows 凭据管理器或 Linux 保密服务中。从不清明文本存储。从不存储在配置文件中。
  </Card>
  <Card title="AES-256-GCM 加密">
    数据库字段使用 AES-256-GCM 加密，采用 12 字节随机非重复数。从旧加密自动迁移。您的数据在静态时被加密。
  </Card>
  <Card title="命令风险分类">
    每个工具和 Shell 命令评为 1-5 风险等级。30 多种危险模式检测：权限提升、破坏性删除、远程代码执行、网络窃取。
  </Card>
  <Card title="人工介入">
    为所有副效果工具采用模态批准。颜色编码的风险级别。在没有您的明确确认的情况下，不会发生危险的事。
  </Card>
  <Card title="限时会话覆盖">
    **OpenPawz 独有。** 为受信任会话（30 分钟/1 小时/2 小时）的 "允许全部" 模式，可自动到期。即使在覆盖模式下，权限提升也被阻止。
  </Card>
</Columns>

<Columns cols={2}>
  <Card title="容器沙盒">
    在 Docker 容器中运行智能体 Shell 命令 — cap_drop ALL、内存/CPU 限制、可配置网络隔离。智能体无法触及您的主机系统。
  </Card>
  <Card title="每智能体策略">
    精细化控制各智能体可访问的工具、渠道和风险级别。
  </Card>
  <Card title="提示注入防护">
    双实现（TypeScript + Rust）、30 多种检测模式、4 个严重级别。传入消息会在到达智能体之前分析。
  </Card>
  <Card title="文件系统沙盒化">
    采用 Tauri 作用域强制，具有 20 多个敏感路径阻挡 — `~/.ssh`、`~/.aws`、`~/.gnupg` 等。可选的全局只读模式阻止所有智能体写入。
  </Card>
  <Card title="出站域名控制">
    可配置的域名允许列表和阻止列表，带有通配符子域名匹配。测试 URL 按钮可验证规则。出站请求会接受窃取模式检查。
  </Card>
  <Card title="凭证审计追踪">
    **OpenPawz 独有。** 每次凭证访问都会记录：操作、工具、允许/阻止、时间戳。完整的安全审计仪表板，带有 JSON/CSV 导出功能。
  </Card>
</Columns>

<Columns cols={2}>
  <Card title="技能验证管道">
    **OpenPawz 独有。** 社区技能会经过安全模式、已知安全列表检查、npm 注册仓库风险情报扫描和安装后沙盒验证。
  </Card>
  <Card title="CSP 实施">
    内容安全策略：`default-src 'self'`，`script-src 'self'`，`object-src 'none'`，`frame-ancestors 'none'`。在平台层面防止 XSS 和注入。
  </Card>
</Columns>

<Columns cols={2}>
  <Card title="TLS 证书固定">
    **OpenPawz 独有。** 自定义 `rustls` 配置仅固定于 Mozilla 根 CAs — 明确排除操作系统信任存储。即使用户机器上的 CA 被妥协也无法劫持提供商流量。
  </Card>
  <Card title="出站请求签名">
    每个 AI 提供商请求在传输前都将通过 SHA-256 签名。`provider ‖ model ‖ timestamp ‖ body` 哈希记录到 500 条目审计环形缓冲区中用于防篡改检测和合规。
  </Card>
  <Card title="内存加密（RAM 清零）">
    API 密钥以 `Zeroizing<String>` 包装 — 通过 `write_volatile` 在丢弃时自动用零覆盖内存。防止内存转储、交换文件和使用释放后漏洞提取密钥。
  </Card>
  <Card title="共享固定 HTTP 客户端">
    跨所有提供商共享带有固定 TLS 配置的单一 `reqwest::Client`。连接池，10 秒连接超时，120 秒请求超时。无每次请求的客户端创建开销。
  </Card>
</Columns>
