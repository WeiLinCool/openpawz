## 三大支柱

<Tabs>
  <Tab title="内存">
    您的智能体**永远不会忘记**。每个重要事实都会自动捕获到向量嵌入并在相关时回忆。

    - **自动捕获** — 智能体从每次对话中提取关键信息
    - **自动回忆** — 相关记忆在智能体回复前注入上下文
    - **记忆宫殿** — 浏览、搜索、编辑关于智能体所知的一切
    - **混合检索** — BM25 + 向量 + MMR + 时间衰减
  </Tab>
  <Tab title="令牌节省">
    **自动会话压缩** — 当对话接近上下文限制时，旧的部分会被摘要。关键事实保存在内存中。完整会话被归档。在长会话中节省 40–60% 令牌。
  </Tab>
  <Tab title="安全">
    零信任，本地优先 — **10 层安全**：
    - **100% 本地** — 没有数据离开您的机器
    - **OS 密钥链** — 凭据存储在 macOS 密钥链 / Windows 凭据管理器 / Linux 密钥服务
    - **风险分类** — 每个工具评级 1-5 分。危险操作需确认
    - **容器沙盒** — 通过资源限制的 Docker 隔离
    - **提示词注入防御** — 双重实施，30+ 检测模式
    - **TLS 证书绑定** — 仅允许 Mozilla 根 CA，排除 OS 信任存储
    - **请求签名** — 每个外发 AI 请求的 SHA-256 哈希用于篡改检测
    - **内存清零** — 删除提供商时，API 密钥会自动从 RAM 中清零
  </Tab>
</Tabs>
