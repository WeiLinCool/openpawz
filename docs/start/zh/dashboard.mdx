## 今日视图

当您启动 OpenPawz 时，**今日**仪表板为您提供您智能体、频道和自动化工具的所有活动的快照。

---

## 仪表板上的内容

<Columns cols={2}>
  <Card title="问候和天气">
    时间感知问候，如果已配置，还包含当地天气状况。
  </Card>
  <Card title="使用统计">
    实时令牌计数、会话成本和输入/输出令牌细分显示在标题条中。
  </Card>
  <Card title="活跃智能体">
    查看哪些智能体现在线，他们的当前会话状态和连接的频道。
  </Card>
  <Card title="最近消息">
    所有频道的最新消息 — 快速访问正在进行的对话。
  </Card>
  <Card title="任务概览">
    来自看板的待处理和进行中的任务，包括截止日期和分配给智能体的任务。
  </Card>
  <Card title="技能输出小部件">
    技能和集成功能可以在仪表板上显示实时数据 — 天气、投资组合、构建状态或任何自定义小部件。
  </Card>
</Columns>

---

## 快速操作

仪表板提供一键访问常见任务：

- **新建聊天** — 与任何智能体开始对话
- **新任务** — 创建任务并分配给智能体
- **新自动化** — 设置定时作业或事件触发器
- **快速设置** — 跳转到提供商或频道配置

---

## 邮箱

如果您配置了电子邮件，仪表板会显示未读邮件并可快速回复。智能体可以分类整理、总结并起草回复。

---

## 自定义

仪表板会适应您的工作区配置文件。不同配置文件（完整版、轻量版、操作员版、频道版、开发版、交易版）显示不同的小部件布局。您可以在**设置 → 工作区**中切换视图并重新排列工作区。
