<Note>
OpenPawz 不仅仅是一个聊天应用 — 它是一个**智能体操作系统**。以下是人们用它构建的内容。
</Note>

## 用例

<Columns cols={2}>
  <Card title="个人 AI 助理" icon="user" href="/docs/start/first-agent">
    在 Telegram 或 WhatsApp 上运行一个了解您喜好、记住过往对话并执行任务的智能体 — 发邮件、日历、网络浏览、智能家庭控制。通过 TTS 大声说出响应并通过语音转文本收听。
  </Card>
  <Card title="多平台客服机器人" icon="headset" href="/channels/overview">
    同时将单个智能体连接到 Discord、Slack 和 Matrix。相同特性，相同内存，不同平台。智能消息拆分自动处理每个平台的限制。
  </Card>
  <Card title="自动化交易平台" icon="chart-line" href="/guides/trading">
    智能体跨三条链交易加密货币 — Coinbase、Solana (Jupiter/Pump.fun)、Ethereum (Uniswap)。策略防护确保一切都处于限定范围内，即使在您睡觉时也是如此。完整审计轨迹。
  </Card>
  <Card title="研究小队" icon="magnifying-glass" href="/guides/orchestrator">
    一个协调员委托给专业智能体 — 网络研究员、数据分析师、撰写员。工作人员并行运行，配备无头 Chrome。小队可以持久化并跨项目复用。
  </Card>
  <Card title="DevOps 自动化" icon="gears" href="/guides/automations">
    Cron 任务、事件触发、沙盒化的 shell 命令。在可视化节点编辑器中连接触发器 → 智能体 → 工具 → 输出。将结果传送到 GitHub Actions、Zapier 或任何 HTTP 客户端。
  </Card>
  <Card title="内容生产线" icon="pen-nib" href="/guides/content-studio">
    在 AI 协助下起草文档。将不同类型的内容路由到专业智能体 — 博客文章、社交媒体、技术文档。智能体研究、写作并通过连接的渠道发布。
  </Card>
  <Card title="语音助手" icon="microphone" href="/guides/voice">
    三类 TTS 提供商（Google、OpenAI、ElevenLabs）具有可配置的声音、速度和语言。自动朗读模式大声读出所有响应。结合 Telegram 或 Webchat 实现全语音驱动的用户体验。
  </Card>
  <Card title="自我改进网络" icon="wand-magic-sparkles" href="/guides/skills">
    智能体在运行时发现和安装功能。智能体遇到新任务时，搜索 PawzHub，安装技能并立即使用 — 所有这一切都通过对话完成。无需重启。
  </Card>
</Columns>
