# 创建您的第一个智能体

智能体是 OpenPawz 的核心。每个智能体都有自己的个性、AI 模型、工具和对话历史。

## 创建智能体

1. 在侧边栏中点击 **智能体**
2. 点击 **创建智能体** 卡片
3. 填写以下信息：
   - **名称** — 给它一个可识别的名称（例如，"研究机器人"，"代码助手"）
   - **简介** — 关于该智能体功能的简短描述
4. 点击 **创建**

就这样 — 您的智能体已准备好聊天。

## 自定义您的智能体

点击任何智能体卡片上的 **编辑** 按钮来配置：

### 个性
| 设置 | 选项 | 描述 |
|---------|---------|-------------|
| **语调** | 随意 / 平衡 / 正式 | 智能体的交流方式 |
| **主动性** | 被动 / 平衡 / 主动 | 智能体自主采取行动的程度 |
| **详细程度** | 简洁 / 平衡 / 详尽 | 回复的详细程度 |

### 模型
每个智能体可以使用不同的 AI 模型。点击模型下拉菜单，从您配置的提供商中选择。使用 `default` 以继承全局模型设置。

### 系统提示
在系统提示字段中添加自定义指令。这会在每次与该智能体的对话中注入这些指令。

### 灵魂文件
当您创建一个智能体时，Pawz 会自动生成三个文件：
- **IDENTITY.md** — 名称、角色、专长、个性
- **SOUL.md** — 价值观和交流风格（可编辑以深度定制）
- **USER.md** — 关于您的学习偏好（随时间增长）

## 与您的智能体聊天

点击任何智能体卡片以打开主聊天视图并选择该智能体。或者点击**智能体停靠栏**（右下角）中的智能体头像以打开小型聊天弹窗。

### 小型聊天弹窗
每个智能体都有自己的浮动聊天窗口 — 就像 Facebook Messenger。您可以同时打开多个窗口，每个窗口与不同的智能体交谈。

### 智能体停靠栏
右下角的停靠栏显示所有您的智能体作为头像圆圈。悬停以查看智能体的名称。点击切换按钮可折叠/展开停靠栏。
