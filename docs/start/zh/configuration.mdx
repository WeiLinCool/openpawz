## 配置概览

OpenPawz 开箱即用地运行，具有合理的默认设置。本页介绍了安装后可以调整的可选设置。

---

## 提供商设置

每个 AI 提供商都需要一个 API 密钥（云端）或是一个运行中的实例（本地）。在**设置 → 提供商**中配置提供商。

<Steps>
  <Step title="打开设置">
    单击侧边栏左下角的齿轮图标，然后选择**提供商**。
  </Step>
  <Step title="添加提供商">
    单击**添加提供商**并从列表中选择：Ollama、OpenAI、Anthropic、Google、DeepSeek、Grok、Mistral、OpenRouter、Moonshot 或自定义。
  </Step>
  <Step title="输入凭证">
    对于云提供商，请粘贴您的 API 密钥。对于 Ollama，请输入主机 URL（默认值：`http://localhost:11434`）。
  </Step>
  <Step title="选择默认模型">
    为新智能体选择默认模型。您可以稍后针对每个智能体进行覆盖。
  </Step>
</Steps>

→ 完整的提供商指南：[提供商](/docs/providers/overview)

## 工作区配置文件

OpenPawz 拥有模块化的侧边栏。选择一个工作区配置文件以仅显示您需要的视图。

| 配置文件 | 可见视图 |
|---|---|
| **全部** | 全部 — 智能体、频道、任务、交易、研究、内容、邮件 |
| **开发者** | 智能体、任务、浏览器、编排器、扩展 |
| **交易者** | 智能体、交易、任务、自动化 |
| **作家** | 智能体、内容工作室、研究、邮件 |
| **简约** | 仅智能体 |

在**设置 → 工作区**中更改配置文件或创建自定义组合。

→ 深入介绍：[模块化工作区](docs/guides/modular-workspace)

## 环境变量

某些功能需要在**设置 → 环境**中设置环境变量：

| 变量 | 用途 |
|---|---|
| `OPENAI_API_KEY` | OpenAI 提供商访问 |
| `ANTHROPIC_API_KEY` | Anthropic 提供商访问 |
| `SMTP_HOST` / `IMAP_HOST` | 电子邮件工具配置 |
| `GITHUB_TOKEN` | GitHub 工具访问 |
| `TAILSCALE_AUTH_KEY` | Tailscale 网格网络 |

环境变量存储在本地且永远不会传输。

## 智能体默认设置

在**设置 → 智能体默认值**中设置新智能体的默认值：

- **默认提供商和模型** — 哪个 AI 支持新智能体
- **默认系统提示** — 基础指令
- **温度和令牌限制** — 生成参数
- **工具访问权限** — 哪些工具默认启用
- **内存设置** — 自动捕获和自动回忆开关

各个智能体可以覆盖任何默认设置。

→ 深入介绍：[智能体指南](/guides/agents)
