# Matrix

连接到 Matrix 服务器，这样用户就可以通过任何 Matrix 客户端（Element, FluffyChat 等）与您的代理进行聊天。

## 安装配置

1. 在 Matrix 服务器上创建一个机器人账号
2. 记录服务器URL、用户名和密码
3. 在 Pawz 中，转到 **设置 → 频道**
4. 选择 **Matrix**
5. 输入：
   - **服务器 URL** — 例如，`https://matrix.org`
   - **用户名** — 机器人的 Matrix ID（例如，`@pawz-bot:matrix.org`）
   - **密码** — 机器人账号密码
6. 启动此频道

## 配置

| 字段 | 必需 | 说明 |
|-------|----------|-------------|
| 服务器 URL | 是 | Matrix 服务器 URL |
| 用户名 | 是 | 机器人 Matrix 用户 ID |
| 密码 | 是 | 机器人账号密码 |
| DM 策略 | 是 | 谁可以给机器人发消息 |
| 允许用户 | 针对白名单 | Matrix 用户 ID |

## 功能特性

- 私信和房间消息
- 每用户会话带记忆功能
- 提示注入扫描
- 通过频道路由规则进行代理路由
- 邀请时自动加入

:::info 支持端到端加密
Matrix 通道桥接使用 `matrix-sdk` 以及 **vodozemac** 进行 Olm/Megolm 加密。E2EE 房间中的消息会被自动解密，回复则会自动加密。设备密钥和房间会话保存在本地 SQLite 加密存储（`~/Documents/Paw/matrix-store/`）中，因此重启后密钥也能保持连续性。
:::

## 社区房间

OpenPawz 配备了一个官方 Matrix 房间用于支持、反馈和常规讨论：

**[#openpawz:matrix.org](https://matrix.to/#/#openpawz:matrix.org)**

可通过 [Element](https://app.element.io/#/room/#openpawz:matrix.org) 或任何 Matrix 客户端加入。

## 提示

- 对于自托管 Matrix（Synapse, Dendrite），使用您服务器的 URL
- 邀请机器人到您希望其活跃的房间
- 使用 Element 或任何 Matrix 客户端进行测试
