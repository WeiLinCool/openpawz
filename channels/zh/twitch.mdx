# Twitch 频道

连接到 Twitch 聊天，让观众可以在您直播时与您的代理互动。

## 设置

1. 为您的机器人创建一个 Twitch 账户(或使用您自己的)
2. 在 [twitchapps.com/tmi](https://twitchapps.com/tmi/) 生成一个 OAuth 令牌
3. 在 Pawz 中，转到 **设置 → 频道**
4. 选择 **Twitch**
5. 输入：
   - **用户名** — 机器人的 Twitch 用户名
   - **OAuth 令牌** — 来自步骤 2
   - **频道** — 要加入的 Twitch 频道(您的直播频道)
6. 启动频道

## 配置

| 字段 | 必需 | 说明 |
|-------|----------|-------------|
| 用户名 | 是 | 机器人的 Twitch 用户名 |
| OAuth 令牌 | 是 | Twitch OAuth 令牌 |
| 频道 | 是 | 要加入的频道名称 |
| 私信策略 | 是 | 谁可以互动 |
| 允许用户 | 适用于允许列表 | Twitch 用户名 |

## 功能

- Twitch IRC 聊天集成
- 每个用户的会话带记忆功能
- 提示注入扫描
- 通过频道路由规则进行代理路由
- 响应提及和命令

## 提示

- 将私信策略设置为 **开放** 以供公共流媒体互动
- 如果只想让管理员或订阅者互动，请使用允许列表
- 消息限制为 Twitch 的最大 500 个字符 - 长回复会自动拆分
- 考虑设置速率限制以避免刷屏
