# Discourse

将您的智能体连接到 Discourse 论坛。您的智能体监控话题，回复帖子，并且可以创建新主题——非常适合社区支持、FAQ 自动化和互动。

## 设置

1. 在您的 Discourse 论坛上创建一个**专用机器人账户**（例如，`paw-bot`）
2. 以管理员身份进入 **管理 → API → 新建 API 密钥**
3. 将范围设置为**单个用户**并选择机器人账户
4. 复制 API 密钥
5. 在 Pawz 中，进入 **设置 → 频道**
6. 选择 **Discourse**
7. 输入：
   - **论坛 URL** — 例如，`https://community.example.com`
   - **API 密钥** — 来自第 4 步
   - **机器人用户名** — 机器人的账户用户名
8. 启动频道

## 配置

| 字段 | 必需 | 描述 |
|-------|----------|-------------|
| 论坛 URL | 是 | 您的 Discourse 实例 URL（不包含尾随斜杠） |
| API 密钥 | 是 | 管理员生成的作用域为机器人用户的 API 密钥 |
| 机器人用户名 | 是 | API 密钥作用域所属的 Discourse 用户名 |
| 监控类别 | 否 | 用逗号分隔的类别标记（留空 = 所有类别）|
| 回复话题 | 是 | 智能体是否自动回复新话题 |
| 创建话题 | 否 | 智能体是否可以创建新话题 |
| 轮询间隔 | 否 | 检查新帖子的频率（默认：30秒，最小：10秒）|

## 连接

Pawz 通过 Discourse 的 **REST API** 连接，以配置的间隔轮询新帖子。机器人在每次请求时使用 API 密钥+用户名头部进行认证。不需要入站网络钩子或公共 URL——这是一个完全 outbound 的连接。

### API 密钥设置（逐步指南）

1. 以**管理员**身份登录到您的 Discourse 论坛
2. 导航至 `/admin/api/keys`
3. 点击 **新建 API 密钥**
4. 描述：`Paw 智能体机器人`
5. 用户级别：**单个用户** → 选择您的机器人账户
6. 点击 **保存**
7. 复制密钥（您不会再次看到它）

<Tip>
使用**单个用户**范围而不是全局 API 密钥。这将机器人限制为机器人账户有权执行的操作。
</Tip>

## 功能

- **话题监控** — 监视类别中的新话题和回复
- **自动回复** — 使用上下文感知的答案回复帖子
- **话题创建** — 智能体可以创建新的话题（可选功能）
- **类别过滤** — 监视特定类别或所有类别
- **每用户会话** — 每位用户的对话具有持续的记忆能力
- **话题上下文** — 在回复之前读取完整的话题线程以获取上下文
- **提示注入扫描** 对于所有传入帖子
- **智能体路由** — 指定特定智能体处理 Discourse

## Discourse 机器人账户提示

<Tip>
- 创建一个专用机器人账户（`paw-bot`）而不是使用您的管理员账户
- 将机器人的**信任等级**至少设置为**1（基础）**，以便它可以在不受限制的情况下发布帖子
- 添加清晰的**个人资料**，比如"我是由 Pawz 提供支持的 AI 助手"以提高透明度
- 上传一个可识别的**头像**（Pawz 徽标效果很好）
- 如果您希望它管理类别，请考虑将机器人设置为**版主**
</Tip>

## 疑难解答

| 问题 | 解决方法 |
|---------|-----|
| 403 禁止访问 | API 密钥可能已过期或作用域设置到错误用户——在管理 → API 中重新生成 |
| 机器人不回复 | 检查"回复话题"是否已启用以及机器人账户是否有发帖权限 |
| 帖子发布到错误类别 | 验证类别标记是否完全匹配（区分大小写，使用连字符而非空格）|
| 被限制速率 | 增加轮询间隔（Discourse 默认速率限制为 60 次/分钟）|
| 机器人回复自己 | 机器人用户名必须完全匹配——智能体会过滤掉自己的帖子 |
| 连接超时 | 验证论坛 URL 是否正确且可以从您的计算机访问 |

## 类别标记

类别标记是类别名称的 URL 安全版本。例如：

| 类别名称 | 标记 |
|---------------|------|
| 一般讨论 | `general-discussion` |
| 支持 | `support` |
| 功能请求 | `feature-requests` |

通过导航到某个类别可以找到标记——标记是 URL 的最后部分：
`https://community.example.com/c/support/5` → 标记是 `support`
