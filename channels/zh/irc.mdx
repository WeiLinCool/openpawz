# IRC

连接到 IRC 网络，以便用户可以在 IRC 频道中与您的智能体聊天。

## 设置

1. 选择一个 IRC 网络（Libera.Chat、OFTC 等）
2. 在 Pawz 中，前往 **设置 → 频道**
3. 选择 **IRC**
4. 输入：
   - **服务器** — 例如，`irc.libera.chat`
   - **端口** — 通常为 `6697`（TLS）或 `6667`（普通）
   - **昵称** — 机器人的 IRC 昵称
   - **频道** — 要加入的以逗号分隔的频道（例如，`#pawz,#general`）
   - **使用 TLS** — 为加密连接启用
5. 启动频道

## 配置

| 字段 | 必需 | 描述 |
|-------|----------|-------------|
| 服务器 | 是 | IRC 服务器主机名 |
| 端口 | 是 | 服务器端口 |
| 昵称 | 是 | 机器人昵称 |
| 频道 | 是 | 要加入的频道 |
| 使用 TLS | 推荐 | 启用 TLS 加密 |
| 密码 | 否 | NickServ 或服务器密码 |
| 私信政策 | 是 | 谁可以私信机器人 |

## 功能

- 频道消息和私人消息
- 每个用户的带记忆会话
- 提示注入扫描
- 通过频道路由规则进行智能体路由
- 断开连接时自动重连

## 提示

- 使用 NickServ 注册您的机器人昵称以防止冒充
- 对于加密连接，请使用 TLS（端口 6697）
- 机器人在被昵称提及或在私信中时会做出回应
